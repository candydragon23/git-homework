### Описание всех таргетов Makefile

**create-structure**
Создает базовую основу проекта включающую директорию для документаций, .gitkeep, .gitignore и requirements.txt

**venv**
Создает новое виртуальное окружение в котором и будут выполняться последующие таргеты

**install-dep**
Устанавливает в виртуальное окружение все зависимости из файла requirements.txt

**install**
Устанавливает текущий проект в режим редактирования

**test-pytest**
Запускает Pytest

**run FILE=name**
Запускает файлы из папки src

**clean**
Удаляет виртуальное окружение

**check-requirements**
Проверяет файлы в папке src на отсутствие необходимых импортов и на наличие не используемых импортов сверяя их с указанными импортами в файле requirements.txt

**typecheck**
Запускает проверку совместимости типов для всех файлов в папке src

**format**
Форматирует все файлы в папке src

**check-format**
Проверяет присутстуют ли в файлах папки src проблемы с форматированием

**check**
Запускает проверку форматирования, зависимостей и соответствия типов
